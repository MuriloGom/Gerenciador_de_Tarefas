# Gerenciador_de_Tarefas
Uma lista de tarefas feita com HTML, CSS (Flexbox/Grid) e JavaScript, podendo adicionar/remover tarefas e marcar como concluída. As tarefas são salvas no LocalStorage, a lista possuí uma barra Scroll down que aparece quando a quantidade de tarefas ultrapassa o limite do campo. Como bônus, há um botão de Dark Mode
